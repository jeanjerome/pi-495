# Archive

Des rapports de mesure rédigés avant le 2026-09-21, dans leur disposition d'origine. Rien de neuf
ne s'y écrit. Le texte normatif est sous [`specs/amont/`](../amont/README.md) ; ce qui reste à faire
est dans `specs/plan.yaml`.

| Document | Objet |
| --- | --- |
| [QUALIFICATION.md](QUALIFICATION.md) | Rapport d'exécution sur la machine de référence. |
| [MODELE-LOCAL.md](MODELE-LOCAL.md) | Installation d'oMLX et configuration du modèle local des deux côtés, oMLX et Pi, avec les pièges qui rendent un modèle inchargeable. |
| [benchmarks/](benchmarks/README.md) | Vitesse du modèle sous la charge que le harnais envoie : protocole, table de comparaison et une fiche par mesure. |

Les travaux, les revues obligatoires et le suivi de l'implémentation de cette époque ont été retirés
de l'arbre : ils se lisent dans l'historique git (`git log --diff-filter=D -- specs/archive`).
