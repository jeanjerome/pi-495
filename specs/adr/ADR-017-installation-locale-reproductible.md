# ADR-017: Installation locale reproductible

**Status:** Acceptée
**Date:** 2026-09-16

## Decision

Verrouiller versions, fournir dépendances et aides de plateforme dans le package, publier SBOM et notices, ne demander aucun service de contrôle distant.

## Consequences

Un moteur local Pi est un profil de première classe ; les téléchargements d’installation sont distincts du fonctionnement local.
